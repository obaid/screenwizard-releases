# ScreenWizard releases

Downloads and the update feed for ScreenWizard for macOS.

**Download the latest version:** [ScreenWizard.dmg](https://github.com/obaid/screenwizard-releases/releases/latest/download/ScreenWizard.dmg)

Requires macOS on Apple silicon or Intel. Installed copies update themselves from `appcast.xml` in this repository.
